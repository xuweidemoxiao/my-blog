## 暗黑模式抽成 Pinia store
- 背景：暗黑模式原本是 `NavBar.vue` 的局部 ref（`isDark`），切换时直接 `document.documentElement.classList.toggle('my-app-dark')`。为集成 md-editor-v3 需要跨组件共享主题状态，遂抽出。
- 项目暗黑模式「单一事实来源」是 `html.my-app-dark` 类，三处依赖它：
  - Tailwind v4：`src/style.css` 里 `@custom-variant dark (&:where(.my-app-dark, .my-app-dark *));`
  - PrimeVue：`src/main.ts` 里 `darkModeSelector: '.my-app-dark'`
  - 组件内 `dark:` 前缀样式
- 改动：
  - 新增 `src/stores/modules/theme.ts`：Options API 风格（对齐 `main.ts` store），`state.isDark` 初始化时从 `document.documentElement.classList` 读一次；`toggle()` / `setDark(v)` 两个 action，DOM 类切换副作用收进 store。
  - `src/components/base-ui/NavBar.vue`：删除局部 `isDark` ref 和 `toggleDarkMode` 里的 DOM 操作，改用 `useThemeStore()`，模板 `v-if="themeStore.isDark"`、`@click="themeStore.toggle()"`。
- 验证：`vue-tsc --noEmit -p tsconfig.app.json` 通过（exit 0）。
- 后续：TextEditor 集成 md-editor 时，`theme` 直接读 `useThemeStore().isDark` 即可，无需再 MutationObserver 监听 DOM。
